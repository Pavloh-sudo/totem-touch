# GP

La mascota se controla desde el widget `GpMascot`. El dibujo o animación se entrega por separado y el widget se encarga de la transición, el movimiento, la accesibilidad y el acento del área.

Estados preparados:

- `idle`
- `wave`
- `thinking`
- `guide`
- `celebrate`
- `error`

Contextos preparados:

- `defaultOutfit`
- `robotics`
- `cutting`
- `manufacturing`
- `machinery`
- `software`
- `careers`

La foto del calendario se mantiene únicamente en `docs/referencias` hasta contar con ilustraciones limpias de la mascota.
